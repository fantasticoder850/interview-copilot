# Interview Copilot — UI design package

Start with `handoff/CODING_ASSISTANT_PROMPT.md`. Give your coding assistant this entire folder alongside your existing repository.

- `designs/`: original concept board and individual dark/light screen references.
- `theme/tokens.css`: reusable semantic CSS variables for both themes.
- `theme/components.css`: reference component styles.
- `preview/index.html`: static browser prototype; navigation and theme switch are functional, other controls illustrate layout only. Open locally or serve this directory with a local static server.
- `handoff/`: implementation instructions, recommended structure and acceptance checks.

Design choice: neutral charcoal / cool white with restrained green accent. The reference screens use fictional sample content and are intended for practice or explicitly authorized interview assistance. The existing repository was not supplied, so the folder structure is advisory and the files are not a drop-in application. No backend integration or real-time functionality is implemented or tested here.
